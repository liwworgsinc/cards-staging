Installation steps

iPhone or iPad

  1. Open this page in Safari.
  2. Tap Share.
  3. Choose Add to Home Screen.
  4. Tap Add.

Android

  1. Tap Install LIW Cards above.
  2. Or open Chrome’s menu.
  3. Choose Install app.
  4. Confirm Install.

Computer

  1. Open this page in Chrome or Edge.
  2. Click Install LIW Cards.
  3. Or use the install icon in the address bar.
  4. Confirm Install.
